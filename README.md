## Projects

### [WildCard](https://github.com/jheroorehj/WildCard)
#### 🏆 AI 부트캠프 어워즈 해커톤 장려상 수상
#### 프로젝트 개요

- 초보 투자자는 투자 손실을 "운이 없었다"는 식으로 감정적으로 넘기는 경우가 많고, 손실을 복기할 인프라가 부족합니다. WildCard는 사용자가 종목명, 매수일, 매도일, 당시 판단 근거를 입력하면 아래 과정을 자동화된 파이프라인으로 처리합니다.

1. 해당 기간의 실제 주가 흐름·기술적 지표 분석
2. 관련 뉴스 요약 및 시장 맥락 파악
3. 손실 원인 분석 (내부/외부 요인 구조화)
4. 투자 패턴·행동경제학 기반 투자 성향 분석
5. 개인화된 학습 가이드 및 체크리스트 제공

### [Safe Guard AI](https://github.com/CGCOCO/Team_4ward) 
#### 🏆 AI 부트캠프 교과형 과정 성과공유회 우수팀 선정
총 3개 트랙이 참여한 성과공유회에서 생성형 AI 트랙의 우수팀으로 선정되었습니다.
#### 프로젝트 개요

- Safe Guard AI는 작업 현장 이미지를 기반으로 안전 위험요소를 분석하는 멀티모달 RAG 서비스입니다. 업로드된 이미지에서 얼굴과 차량 번호판을 마스킹한 뒤, 이미지 속 작업 상황과 위험요소를 추출하고 RAG 기반 검색을 통해 관련 사고사례와 산업안전보건 법령을 찾아 위험 분석 리포트를 생성합니다.
